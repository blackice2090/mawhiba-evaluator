# Phase 2J Gold dataset — `cases.jsonl` schema

One JSON object per line, `GapGoldCase` in `src/evals/research_engineering_gap/dataset.py`
(`extra="forbid"`). Regenerated by `scripts/generate_phase2j_gold.py` (language packs in
`generate_phase2j_gold_core.py`, scenarios in `generate_phase2j_gold*.py`).

**Authoring rule.** Expectations are authored from each case's own source text and the Phase 2J
policy (`docs/phase2j_research_engineering_gap.md`, ADR-021). The generator imports no Phase 2J code
and never runs the system; a test enforces that. Three things are kept apart in every case:

| Field | Meaning |
|---|---|
| `claims`, `patent`, `product`, `oss`, `cutoff`, `nd` | CASE INPUT: authoritative source and claim text; `nd` is the Phase 2I script (the features and whether they are disclosed) |
| `script` | SCRIPTED MODEL RESPONSE for the three Phase 2J calls (`extract`, `link`, `counter`, per claim). Possibly wrong or adversarial on purpose. `"$LEAK"` anywhere is replaced by a hidden-prompt line; a string value (`provider_error`, `parse_error`, `refusal_leak`, `error_leak`) is a failed call |
| `expected` | the deterministic behaviour that is CORRECT given that response |
| `truth` | separate MODEL-JUDGMENT ground truth: the correct linkage relation per limitation excerpt (`links`), whether a passage is one proposition or two (`propositions`), excerpts that should never have been admitted (`inadmissible`), counterevidence the model should have found (`counter`), instruction-like source strings (`injection`) |

A structurally valid but semantically wrong model judgment is therefore measured, never declared
correct: `expected` says what the system must do with the response it was given; `truth` says what the
model should have said.

## Other fields

`language` (`en`/`ar`/`mixed`), `categories`, `bounds` (`GapAssessmentBounds`), `no_model`,
`drop_sufficiency` (Phase 2E stripped before Phase 2I runs), `retract_academic`, `interrupt_before`
(resume from a checkpoint), `rerun` (replay over the finished run), `twin` (`prose`: same typed facts
with free prose injected everywhere; `order`: every proposal list reversed), `mutate` (`claim_edit`,
`upstream_mutation` before FINALIZE), `prose` (the prose a prose twin injects, as data), `controls`
(`["*"]` = every negative control; inapplicable ones are skipped, and each mechanism is attempted on at
most 4 applicable cases per language).

## `expected` keys

Per claim; keys for a claim other than the first take a `C-002:` prefix. `X.includes` / `X.excludes`
compare as subsets. Claim: `claim.posture`, `claim.reasons`, `claim.has_diff`, `claim.existence`,
`claim.linkage`. Hypothesis: `hyp.exists`, `hyp.posture`, `hyp.kind`, `hyp.existence`, `hyp.linkage`,
`hyp.corroboration`, `hyp.scope`, `hyp.scope_effect`, `hyp.review_complete`, `hyp.missing`,
`hyp.materiality`. Records: `lim.types`, `lim.excerpts`, `lim.quality`, `lim.n`, `cap.excerpts`,
`cond.dims`, `cond.n`, `link.relations`, `link.n`, `counter.kinds`, `counter.matches`, `counter.n`,
`narrowing.n`, `narrowing.current_only`, `chron.buckets`, `chron.counter_buckets`, `stmt.*`, `val.*`.
Ledger: `rejected` (refusal reasons), `issues` (claim-level issue codes), `run.issues`. Run:
`run.status`, `run.model_calls`, `run.search_calls`, `run.claims`, `run.hypotheses`. Behaviour:
`replay.*`, `resume.same`, `prose.same`, `order.same`, `ids.same`, `immut.upstream_identical`,
`bind.mutation_detected`. `indep.units` lists, per unit kind, whether it counts as independent.

## What is measured

* **45 deterministic quality families**, each exactly 1.0 with a real denominator, plus
  `per_language_contract_accuracy` per language. A family with no opportunity is `None`.
* **4 model-judgment families**, reported honestly and not required perfect:
  `semantic_linkage_accuracy`, `same_span_proposition_judgment_accuracy`,
  `limitation_semantic_admissibility_accuracy`, `counterevidence_recall_accuracy`.
* **138 release gates** (`gates.py`), each `violations/opportunities` from the case's own facts, scored
  from the serialized run and the upstream records; no denominator floor; all must be zero with a
  non-zero aggregate denominator.
* **55 negative controls** (`controls.py`): each simulates a trust mechanism being bypassed and must be
  detected, by the contract (for the intended reason, matched by regex) or by a gate firing.
  `test_controls_are_not_vacuous...` shows a control stops being caught when its production mechanism is
  disabled.

## Same-span HYBRID (recorded Gold requirement)

Two admissible limitation types over the SAME exact span are two distinct proposition records. Whether
the passage really states two propositions is a model judgment code cannot prove. The dataset therefore
holds a genuinely dual passage (HYBRID is correct) and passages mislabeled twice (HYBRID is manufactured),
and `same_span_proposition_judgment_accuracy` reports the second honestly (currently 3/9). No similarity
scoring is used.
